NYAKINOMBE MIRACLE CENTRE CHURCH WEBSITE

Files:
- index.html = complete website
- logo.png = church logo supplied in the conversation
- church.jpg = church building photo supplied in the conversation

TO USE ON A PHONE:
1. Extract this ZIP.
2. Open index.html in a browser to preview it.
3. For publishing, upload index.html, logo.png and church.jpg to a static website host.

BEFORE PUBLISHING:
Replace the placeholder church phone/email/social links and update service times, sermons and events.

IMPORTANT:
The Prayer Request form is currently a demonstration form. It does not send messages to the church until it is connected to a form/email service.
